# Student Academic Assistant

## Problem Statement

Students have to keep track of marks and attendance for different subjects. Managing this information manually can make it difficult to calculate averages, compare performance, and understand academic progress.

The Student Academic Assistant provides a simple way to enter, manage, and analyze academic information in one place.

## Scope

The project focuses on managing and analyzing basic student academic information.

It includes:

- Student information
- Subject-wise marks
- Subject-wise attendance
- Input validation
- Academic record display
- Marks analysis
- Performance summary
- Marks and attendance graphs
- Interactive dashboard

## Target Users

The main target users are students who want a simple way to maintain and understand their academic performance.

## High-Level Features

- Add student information
- Add academic records
- Validate marks and attendance
- View academic records
- Calculate total and average marks
- Find highest and lowest marks
- View academic performance through a dashboard
- View marks and attendance graphs
