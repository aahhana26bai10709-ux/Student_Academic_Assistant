# Student Academic Assistant

## Project Description

Student Academic Assistant is a simple Python project made to help students keep track of their academic performance. It allows students to enter subject-wise marks and attendance, checks the entered data, calculates basic performance statistics, and displays the information through an interactive dashboard.

## Features

- Student information management
- Add subject-wise marks
- Add subject-wise attendance
- Validate marks and attendance
- View academic records
- Calculate total and average marks
- Find highest and lowest marks
- Display academic tables
- Display marks and attendance graphs
- Interactive Streamlit dashboard

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- PyCharm
- Git
- GitHub


## Project Modules

1. Student Management

3. Marks Analyzer
